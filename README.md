# TPI-Organizacion-Empresarial
## Sistema de Gestión de Viviendas Personalizadas

## Descripción del proyecto

Este proyecto consiste en organizar y mejorar los procesos de una empresa dedicada a la construcción e instalación de viviendas personalizadas.

El objetivo es desarrollar una propuesta de sistema informático que permita registrar los datos de los clientes, administrar las obras, controlar los materiales disponibles y realizar un seguimiento de las instalaciones.

También buscamos mejorar la comunicación entre los distintos sectores de la empresa, evitando errores y manteniendo la información organizada y actualizada.

## Sectores involucrados

Asesoramiento Comercial: recibe las solicitudes de los clientes y registra sus requerimientos.

Obras: organiza las fechas, coordina las instalaciones y controla la calidad de los trabajos.

Depósito: verifica la disponibilidad de materiales y gestiona su reposición.

Sistema Informático: registra y actualiza la información relacionada con las compras, los materiales y las obras.

## Herramientas utilizadas

BPMN.io para representar los procesos de la empresa.

Git y GitHub para controlar las versiones y organizar la documentación.

GitHub Projects para gestionar las actividades del proyecto.

Integrantes

Trabajo práctico realizado de manera individual.

Durante el desarrollo de este trabajo utilicé ChatGPT como una herramienta de apoyo para comprender mejor las consignas, organizar las actividades y resolver algunas dudas sobre las herramientas utilizadas.

Principalmente, realicé consultas sobre cómo representar los procesos de la empresa mediante BPMN, cómo utilizar Git y GitHub para controlar las versiones del proyecto y cómo organizar las Historias de Usuario en un tablero ágil.

Los prompts utilizados fueron preguntas relacionadas con las dificultades que iban apareciendo durante el desarrollo del trabajo. Busqué obtener explicaciones y ejemplos que me permitieran comprender los procedimientos antes de aplicarlos.

Las respuestas de la inteligencia artificial fueron utilizadas como orientación. Revisé las propuestas, realicé modificaciones en el diagrama BPMN y fui comprobando las conexiones y decisiones representadas. También organicé el repositorio, creé una rama secundaria, registré los cambios mediante commits y realicé un Pull Request.

Considero que la inteligencia artificial fue útil para aprender a utilizar herramientas que no conocía completamente. Sin embargo, entiendo que sus respuestas pueden contener errores y que es importante revisarlas, comprenderlas y adaptarlas a las necesidades del proyecto, en lugar de copiarlas sin analizarlas.
