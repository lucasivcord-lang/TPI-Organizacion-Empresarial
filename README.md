# TPI-Organizacion-Empresarial
Sistema de Gestión de Viviendas Personalizadas

Descripción del proyecto

Este proyecto consiste en organizar y mejorar los procesos de una empresa dedicada a la construcción e instalación de viviendas personalizadas.

El objetivo es desarrollar una propuesta de sistema informático que permita registrar los datos de los clientes, administrar las obras, controlar los materiales disponibles y realizar un seguimiento de las instalaciones.

También buscamos mejorar la comunicación entre los distintos sectores de la empresa, evitando errores y manteniendo la información organizada y actualizada.

Sectores involucrados

Asesoramiento Comercial: recibe las solicitudes de los clientes y registra sus requerimientos.

Obras: organiza las fechas, coordina las instalaciones y controla la calidad de los trabajos.

Depósito: verifica la disponibilidad de materiales y gestiona su reposición.

Sistema Informático: registra y actualiza la información relacionada con las compras, los materiales y las obras.

Herramientas utilizadas

BPMN.io para representar los procesos de la empresa.

Git y GitHub para controlar las versiones y organizar la documentación.

GitHub Projects para gestionar las actividades del proyecto.

Integrantes
